    How the box works
    • A Docker container on the gVisor kernel, with no network and a read-only disk.
    • It runs as user nobody, with every capability dropped.
    • At most 256 MB of memory, half a CPU core and 64 processes.
    • Every command gets 10 seconds; then the box is cleaned for the next one.
    • The brain is mimo-v2.6-pro on Vultr Serverless Inference. The box runs on a Vultr VM in Stockholm.
    • Two traps on the server tell whether anything got out: a secret file and a secret address.
